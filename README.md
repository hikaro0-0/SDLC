# Астролог

**Астролог** — учебное приложение для определения знака Зодиака пользователя по дате рождения и отображения астрологической информации о соответствующем знаке.

Проект разработан в рамках учебного задания и демонстрирует работу с графическим интерфейсом, вводом и проверкой пользовательских данных, а также взаимодействие между несколькими формами приложения.

## 🎯 Назначение проекта

Основная задача приложения — определить знак Зодиака пользователя на основании введённой даты рождения и вывести соответствующую астрологическую информацию.

Программа должна выполнять следующие действия:

1. Открывать главное окно приложения.
2. Отображать кнопку **«Узнать свой знак Зодиака»**.
3. При нажатии на кнопку открывать дополнительную форму для ввода даты рождения.
4. Не использовать стандартный элемент управления для ввода даты.
5. Проверять корректность введённых пользователем данных.
6. Определять знак Зодиака по дате рождения.
7. Отображать вычисленный знак Зодиака на главной форме.
8. Отображать астрологическую информацию о соответствующем знаке.
9. Сохранять последние введённые данные.
10. При повторном открытии формы восстанавливать последние введённые значения.
11. При вводе некорректных данных выводить сообщение об ошибке.

## 📥 Входные данные

Пользователь вводит дату своего рождения в дополнительной форме.

| Параметр | Описание                    |
| -------- | --------------------------- |
| День     | День рождения пользователя  |
| Месяц    | Месяц рождения пользователя |
| Год      | Год рождения пользователя   |

Для ввода даты **не используется стандартный элемент управления даты**. Данные вводятся с помощью отдельных элементов интерфейса.

Перед вычислением знака Зодиака выполняется проверка введённых значений.

### Проверка данных

Программа должна проверять:

* заполнены ли все необходимые поля;
* является ли день допустимым числом;
* является ли месяц допустимым числом;
* является ли год допустимым числом;
* существует ли указанная дата;
* соответствует ли введённая дата допустимому календарному значению.

Если данные некорректны, пользователь получает сообщение об ошибке, а вычисление знака Зодиака не выполняется.

---

## 💾 Сохранение последних данных

Последние введённые пользователем данные должны сохраняться в приложении.

При повторном открытии формы ввода даты ранее введённые значения должны автоматически восстанавливаться.

Это позволяет пользователю не вводить дату заново при каждом открытии дополнительной формы.

## 🖥️ Интерфейс приложения

### Главное окно

Главное окно содержит:

* кнопку **«Узнать свой знак Зодиака»**;
* поле для отображения определённого знака Зодиака;
* область для отображения астрологической информации.

Изначально информация о знаке может отсутствовать до тех пор, пока пользователь не введёт дату рождения.

### Форма ввода даты

При нажатии на кнопку **«Узнать свой знак Зодиака»** открывается дополнительная форма.

На форме располагаются:

* поле для ввода дня;
* поле для ввода месяца;
* поле для ввода года;
* кнопка подтверждения ввода;
* возможность закрыть форму.

При повторном открытии формы последние введённые значения восстанавливаются.
